# Sistem Informasi Manajemen Magang — Rumah BUMN Yogyakarta

**Tools:** Laravel, PHP, SQLite, UML
**Jenis:** Skripsi (Tugas Akhir) — Research and Development (R&D)
**Institusi:** Rumah BUMN Yogyakarta

## 📌 Latar Belakang
Proses pengelolaan magang di Rumah BUMN Yogyakarta — mulai dari penyampaian informasi, pendaftaran, seleksi peserta, hingga pengelolaan divisi per batch — masih belum terintegrasi dalam satu sistem, sehingga menyulitkan admin dalam mengelola data secara terpusat dan efisien.

## 🎯 Tujuan
1. Mengembangkan Sistem Informasi Manajemen Magang berbasis website sesuai kebutuhan pengguna
2. Mengukur kualitas sistem berdasarkan standar **ISO/IEC 25010:2023**, mencakup aspek *Functional Suitability*, *Performance Efficiency*, *Interaction Capability*, dan *Reliability*

## 🔧 Metode Pengembangan
Menggunakan pendekatan **Research and Development (R&D)** dengan model **Prototype**, terdiri dari 5 tahap:
1. Communication
2. Quick Plan
3. Modeling Quick Design
4. Construction of Prototype
5. Deployment, Delivery & Feedback

Sistem dibangun dengan framework **Laravel** (PHP) dan database **SQLite**, dimodelkan menggunakan **UML**.

## ⭐ Fitur Utama
1. Penyampaian informasi magang terpusat
2. Pengaturan periode pendaftaran otomatis per batch
3. Formulir pendaftaran online
4. Seleksi peserta bertahap
5. Pengelolaan divisi per batch
6. Notifikasi hasil seleksi via WhatsApp (semi-otomatis)

## 📊 Hasil Pengujian Kualitas (ISO/IEC 25010:2023)

| Aspek | Metode Pengujian | Hasil |
|---|---|---|
| Functional Suitability | Uji oleh 2 validator ahli | **100%** (Sangat Layak) |
| Performance Efficiency | GTmetrix | Rata-rata waktu muat **2,13 detik**, skor **88,2%** (Excellent) |
| Interaction Capability | Kuesioner 10 responden (2 admin, 8 peserta/alumni) | **87,79%** (Sangat Baik) |
| Reliability | WAPT | Error rate **0%**, success rate **100%** |


## 💡 Pembelajaran
Project ini melatih penerapan metodologi pengembangan perangkat lunak secara formal (R&D dengan model Prototype), serta pengujian kualitas sistem menggunakan standar internasional ISO/IEC 25010:2023 — mencakup pengujian fungsional, performa, usability, dan reliabilitas sistem secara terukur.
